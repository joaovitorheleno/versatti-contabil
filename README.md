# versatti-contabil
Sistema desenvolvido para a empresa Versatti Contabilidade, o propósito seria um sistema para apresentação da empresa e facilidade do usuário para contatar serviços de contabilidade

## Padrão do projeto

- Tudo deve ser em Inglês
- Pastas e arquivos devem ser em minúsculo e devem ser separados por '-', **exemplo: client-user.entity.ts**
- Migrations devem ser separadas por letras maiúsculas
